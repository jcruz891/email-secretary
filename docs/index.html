📬 Email Secretary

A personal AI agent that organizes my Gmail every morning. Built with LangChain and LangGraph as a student learning project.

What it does

  • Reads new emails in my inbox
  • Sorts each one into a category and adds a Secretary/… label
  • Flags likely spam and phishing
  • Writes reply drafts for emails that need an answer and saves them to Gmail Drafts. It never sends anything.

Who can use it

This is a personal tool. It runs on my own computer and is only used with my own Gmail account. It is not offered as a service to other people.
