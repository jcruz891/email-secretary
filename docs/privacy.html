Privacy Policy

Email Secretary · Last updated November 5, 2026

Email Secretary is a personal project that runs on its author's own computer and is used only with the author's own Gmail account.

What data it accesses

With permission granted through Google sign-in, the app reads the sender, subject and text of recent inbox emails. It adds Gmail labels to those emails and creates reply drafts. It does not send, move or delete email.

How data is used

Email text is sent to the Anthropic API (Claude) only to decide each email's category and to write reply drafts. Results are written back to the same Gmail account as labels and drafts, and a local log is kept on the author's computer.

Sharing and storage

No email data is sold, shared or stored on any server run by this project. Apart from the Anthropic API call described above, data stays in Gmail and on the author's computer. Google sign-in tokens are stored only on that computer.

Google API data

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be revoked at any time from Google Account → Third-party connections.

Contact

Questions: open an issue at github.com/jcruz891/email-secretary.
